Aviso de Privacidad

Última actualización: Septiembre de 2026


Este Aviso de Privacidad describe cómo recopilamos, utilizamos y protegemos la información que nos proporciona el establecimiento para poder realizar este sitio web (en adelante referido como el "Sitio").


1. Datos que Recopilamos

Para la elaboracion del sitio web recopilamos unicamente la información necesaria.

  • Nombre del Establecimiento:Para identificar el establecimiento al cual va dirigida esta pagina
  • Ubicacion:Para que el cliente conozca la ubicación del establecimiento y pueda conocerlo.
  • Teléfono / WhatsApp / Correo:Contacto directo hacia el establecimiento

2. Finalidad del Tratamiento de Datos

Los datos solicitados se utilizan exclusivamente para los siguientes fines:

  • Enrutar y dirigir al cliente sobre el establecimiento correspondiente.
  • Generar la comunicación directa mediante su numero telefonico y/o correo.
  • Tener contacto con el establecimiento.

3. Transferencia a Terceros y Aplicaciones Externas

No vendemos, alquilamos ni compartimos los datos proporcionados con terceros para fines publicitarios.


4. Uso de Cookies y Almacenamiento Local

Este sitio web puede utilizar almacenamiento local en el navegador únicamente para mantener la estructura y fabricacion del sitio No rastreamos tu actividad fuera de nuestro sitio.


5. Derechos del Usuario

Puedes solicitar en cualquier momento la rectificación o eliminación de los datos proporcionados poniéndote en contacto directo con el creador del sitio a través de WhatsApp.
